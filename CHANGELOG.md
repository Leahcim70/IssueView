# Changelog

## 0.2.2

- Add the IssueView logo for the Marketplace and extension list.

## 0.2.1

- Sign in with the minimal `read:user` scope; request `repo` only for private repositories.
- Add command to grant access to private repositories.
- Send `IssueView` as User-Agent.
- Distribute the VSIX through GitHub releases instead of the `downloads/` folder.

## 0.2.0

- Rename the extension to IssueView.
- Add English and German UI using native VS Code localization.
- Localize commands, filters, loading states, empty states and errors.
- Add English and German documentation and localization tests.

## 0.1.0

- Initial German-language prototype with repository detection, GitHub authentication, issue list, status filter and pagination in the secondary sidebar.
